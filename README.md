# CREATURE — Interactive Observation

Одностраничный интерактивный сайт-экспириенс: маленькое тёмное птицеподобное
существо на правой стороне экрана поворачивает голову и следит огромными
чёрными глазами за курсором.

Стек намеренно минимальный — HTML + CSS + ES-модуль без UI-библиотек и без
внешних зависимостей в рантайме. Секвенция кадров персонажа рисуется на
`<canvas>`.

## Запуск

```bash
npm install      # sharp — нужен только для генерации кадров
npm run dev      # http://localhost:4173
```

Кадры уже сгенерированы и лежат в репозитории, поэтому сайт открывается сразу.
Отдельная сборка не требуется — это статические файлы, любой веб-сервер подойдёт.

```bash
npm run build    # перегенерировать кадры и проверить целостность проекта
npm run frames   # только перегенерировать кадры
```

## Структура

```
index.html                        разметка первого экрана
styles.css                        оформление, адаптивность, reduced-motion
main.js                           загрузка секвенции, canvas, слежение за курсором
public/experience/frames/
  base.webp                       неподвижный слой: корпус, оперение, лапы, амулеты
  frame_000…239.webp              240 кадров поворота головы
  poster.webp                     полный кадр «смотрит прямо»
  manifest.json                   геометрия сцены и параметры секвенции
tools/creature.mjs                процедурное описание персонажа (SVG)
tools/generate-frames.mjs         рендер кадров в WebP
tools/build.mjs                   сборка и проверка
tools/serve.mjs                   статический сервер для разработки
```

## Как устроен персонаж

`tools/creature.mjs` описывает существо один раз с фиксированным seed, а каждый
кадр — это проекция той же геометрии при другом угле поворота головы. Перья,
волоски, маска, клюв, глаза и амулеты заданы в сферических координатах головы,
поэтому между кадрами ничего не «плавает» и не деформируется: меняется только
ракурс. Диапазон поворота — ±0.92 рад (≈ ±53°), кадр 0 — взгляд максимально
влево, кадр 239 — максимально вправо, кадр 119 — прямо на зрителя.

Персонаж разделён на два слоя. Неподвижное тело (`base.webp`) грузится один раз,
а 240 кадров содержат только голову — это вчетверо легче, чем полные кадры, и
позволяет держать их крупнее. Canvas складывает слои по координатам из
`manifest.json`.

### Замена на другую графику

Отрисовка не завязана на процедурный рендер: `main.js` читает `manifest.json` и
рисует то, что в нём описано. Чтобы поставить свою графику — отрисованную,
фотографическую или 3D-рендер — достаточно положить в `public/experience/frames/`
свои `base.webp` и `frame_NNN.webp` и поправить в манифесте `count`, `stage` и
`head` (положение и размер области головы внутри сцены). Если голова не
вынесена отдельным слоем, укажите в `head` полный размер сцены и положите в
`base.webp` прозрачный пиксель.

## Взаимодействие

- **Курсор** — горизонтальное положение выбирает кадр; движение сглажено
  инерцией (`lerp`), поэтому наблюдение выглядит живым, а не механическим
  переключением картинок.
- **Покой** — если пользователь замер, добавляется едва заметное «дыхание».
- **«Поймать взгляд»** — существо медленно переводит взгляд прямо на зрителя и
  удерживает его около двух секунд.
- **Touch** — реакция на касание и движение пальца; кастомный курсор скрыт.
- **Загрузка** — сначала грузится редкая сетка кадров (каждый шестой), поэтому
  сайт становится интерактивным быстро; остальные кадры догружаются фоном, а до
  их появления берётся ближайший загруженный.
- **`prefers-reduced-motion`** — инерция, «дыхание», кастомный курсор и анимации
  появления отключаются; слежение остаётся, потому что это суть страницы.

## Адаптивность

Проверено от 320 px до 2560 px, горизонтального скролла нет. На планшетах
заголовок и кнопка уменьшаются, персонаж остаётся справа. На мобильных существо
становится фоновым главным объектом сверху, текстовый блок уходит вниз, а метрика
`LIVE / РЕАКЦИЯ` скрывается на самых узких экранах.
